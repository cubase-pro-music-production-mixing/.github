## Troubleshooting Common Issues

Performance problems? Disable unused tracks, stream samples from an SSD, and increase the buffer for mixing.  
License/activation? Re-enter the activation code if the licence manager reports an expired session.  
Compatibility? Update the licence manager before installing a new Cubase version.  
Update failures? Close all Steinberg applications before updating to avoid service conflicts.
